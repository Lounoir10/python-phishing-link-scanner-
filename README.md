# Python Phishing Link Scanner

## About the Project
This is a beginner-friendly Python project created as part of a cybersecurity mini challenge.
The program checks URLs for basic phishing warning signs using conditional statements and string methods.

## What I Learned
- Python functions
- Conditional statements (if, elif, and else)
- The in operator
- String methods
- Using print() to display output

## Limitations
This is a basic educational project, not a complete phishing detection system. A URL that passes these checks is not necessarily safe.
